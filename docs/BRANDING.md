# Identidad de Auralogic Citas

Nombre del producto: **Auralogic Citas**. Nombre del paquete y repositorio: `auralogic-citas`. Sitio del estudio: [auralogic.dev](https://auralogic.dev/).

La identidad usa el monograma A existente de Auralogic, superficies oscuras `#0A0A0A`, texto marfil `#F5F5F0` y acento verde ácido `#C8FF4D`. El favicon es un SVG local; no requiere servicios externos.

`src/config/brand.ts` centraliza el nombre, la web, el repositorio y el enlace comercial. `Brand.astro` y `StudioCredit.astro` aplican la identidad y atribución en la app.

## Atribución y contacto

La app y el README enlazan al estudio y permiten solicitar una implementación a medida. Los enlaces de contacto contienen UTM que identifican la herramienta; los enlaces de atribución apuntan directamente al sitio. No se instala seguimiento ni se envían registros de clientes a Auralogic.

## Código y marca

El código está bajo AGPL-3.0-only y puede modificarse según sus términos. La licencia del código no concede derechos de marca ni permite presentar un fork como un producto oficial del estudio. Para un fork con identidad propia, cambia la configuración, los recursos gráficos y los metadatos. No hay una obligación adicional de conservar enlaces comerciales que modifique la licencia AGPL.

Las obligaciones de licencia y avisos de copyright permanecen según LICENSE. Conserva la atribución de las contribuciones y no añadas requisitos de backlinks como condición de uso del código.
